## ✨ Features

- **Dual Radial Dial:** Outer glowing ring visualizes your remaining focus countdown, while an inner sinusoidal liquid wave shows real-time daily water intake progress.
- **Mindful Sip Breaks:** Automatically prompts you to hydrate and rest your eyes after each 25-minute focus sprint.
- **Immersive Focus Audio:**
  - 🌧️ Gentle Rain (seamless offline loop)
  - 🌊 Forest Stream (seamless offline loop)
  - 🪐 Deep Space / Brown Noise (seamless offline loop)
  - 🎵 Lo-Fi Pulse (seamless offline loop)
  - 🔔 Tibetan Singing Bowl chime on session transitions
  - 💧 Water droplet haptic sound when logging drinks
- **Spotify Integration:** 1-tap direct launch into curated Spotify focus playlists (Deep Focus, Lo-Fi Beats, Peaceful Piano, Synthwave) or custom playlist URLs. App audio mixes gracefully over music without cutting off Spotify.
- **1-Tap Quick Hydration:** Rapid logging for Glass (200ml), Mug (350ml), Bottle (500ml), or custom amounts.
- **Activity & Streaks:** Daily focus statistics, hydration history timeline, and streak tracking.
- **100% On-Device Privacy:** Zero accounts, zero tracking, zero external database calls.

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev) (v3.24+)
- Xcode 15+ (for iOS deployment)
- macOS with arm64 support

### Running Locally
```bash
# Clone or navigate to the repository
cd hydropulse

# Install dependencies
flutter pub get

# Run on macOS desktop or connected iOS device/simulator
flutter run
```
